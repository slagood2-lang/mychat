나만의 차트 — 사용법
====================

[홈페이지로 쓰기]
- 홈페이지 주소(https://아이디.github.io/mychart/)를 열면 설치 없이 코인 차트·스캐너·크립토 종목 찾기가 됩니다. 휴대폰도 됩니다.
- 주식·선물·지수(SI1!, AAPL, 005930, KOSPI…)는 PC에서 아래 서버를 켠 뒤, 홈페이지 상단 ⋯ → 「PC 서버 연결」 → 「연결」.
  크롬이 이 기기·로컬 네트워크 접근을 물으면 「허용」. (한 번 「차단」하면 주소창 왼쪽 아이콘 → 사이트 설정에서 다시 허용)
- 홈페이지와 http://localhost:8000 은 저장 공간이 따로입니다. 관심목록·그림을 옮길 때는 ⋯ → 백업 저장 / 백업 불러오기.

[처음 한 번]
1) 파이썬 설치 (https://www.python.org/downloads/)
   윈도우 설치 첫 화면에서 "Add python.exe to PATH" 체크.
2) 이 폴더의 「start_chart.bat」 더블클릭 (맥은 「start_chart.command」)
   - yfinance(야후 데이터)가 없으면 자동 설치됩니다.
   - 브라우저에서 http://localhost:8000 이 열립니다.
   - 검은 창을 닫으면 서버가 꺼집니다. 차트 볼 때는 켜 두세요.
3) 바이낸스 종목만 볼 때는 서버 없이 index.html 을 크롬으로 바로 열어도 됩니다.

[데이터가 어디서 오나]
- 바이낸스 USDT-M 선물(크립토 + TradFi): 브라우저가 바이낸스 공개 API에서 직접. 실시간(웹소켓).
- SI1!·GC1! 같은 선물, 미국·한국 주식, 지수(SPX, KOSPI, DXY…): 내 PC 서버가 야후 파이낸스에서. 30초마다 갱신, 거래소에 따라 10~20분 지연.
- 크립토 시가총액·트렌딩: 코인게코 무료 API (분당 약 5회, 서버가 10분 저장).
- API 키, 로그인, 주문 기능은 없습니다.

[심볼 입력]
아무 글자나 누르면 검색창이 뜹니다.
  BTC, ETH            → 바이낸스 무기한 (BTCUSDT)
  SI1! GC1! CL1! NQ1! → 은·금·원유·나스닥 선물 (야후 SI=F 등, 근월물 연결)
  AAPL, NVDA, BRK.B   → 미국 주식
  005930, 삼성전자     → 한국 주식 (코스피·코스닥 자동 구분)
  SPX NDX KOSPI KOSDAQ DXY VIX US10Y USDKRW → 지수
  NASDAQ:TSLA, KRX:000660, BINANCE:SOLUSDT.P 처럼 트레이딩뷰 표기도 됩니다.

[트레이딩뷰처럼 쓰기]
- 상단: 타임프레임(1분~12달), 지표, 로그, 자석, 사진(차트 PNG 저장)
- 지표: 「지표」 → 추가. 차트 왼쪽 위 범례에 마우스를 올리면 숨기기·설정·지우기. 이름 두 번 누르면 설정.
  거래량, MA, EMA(여러 개), 볼린저, Nadaraya-Watson Envelope [LuxAlgo], TD Sequential(숫자·13·TDST선),
  자동 로그 피보(스캐너 기준), 겹침 구간(스캔 결과), WaveTrend [LazyBear], RSI, MACD
  지표 구성은 모든 종목에 똑같이 적용되고 저장됩니다.
- 그리기(왼쪽): 추세선, 수평 레이, 수평선, 피보나치 되돌림(로그). 두 점 클릭으로 그립니다.
  그림을 누르면 선택 → 끌어서 옮기기, Delete로 지우기, 두 번 누르기 또는 오른쪽 클릭으로 설정.
  피보 설정: 레벨 추가·색·반전·로그 기준·「새 피보 기본값으로 저장」.
  그림은 종목별로 저장되고, 타임프레임을 바꿔도 같은 자리에 남습니다.
- 오른쪽 목록: 관심목록 / 스캔 결과 / 찾기 결과. ↑↓ 키로 다음 종목.
  관심목록 ⋯ 메뉴: 새 목록, 구분선, 정렬, 트레이딩뷰 목록 가져오기(.txt), 트레이딩뷰 형식으로 저장.
- 단축키: Alt+T 추세선, Alt+H 수평선, Alt+F 피보, Alt+R 차트 맞추기, Esc 취소.

[스캐너]
기존 로그 피보 스크리너와 같은 조건. 대상에 「현재 관심목록」「종목 찾기 결과」를 고르면
주식·선물도 스캔합니다. 종목 이름을 누르면 내 차트로 열리고, 「겹침 구간」 지표에 지지·저항 띠가 표시됩니다.

[종목 찾기]
시장(크립토·미국·한국) × 기준(시가총액, 거래대금, 거래량 급증, 꾸준한 상승, 인기·트렌딩, 오늘 상승률).
꾸준한 상승 = 최근 120일 로그 가격 회귀의 R²(매끄러움) × 그 기간 추세 수익률. 상장 120일 미만은 제외. R²·3개월 수익률·200일선 필터.
「이 결과로 피보 스캔」을 누르면 찾은 종목을 바로 스캐너로 넘깁니다.

[백업]
관심목록·지표·그림은 이 브라우저에 저장됩니다. 상단 ⋯ → 「백업 저장」으로 파일로 받아 두세요.
(브라우저 데이터를 지우거나 다른 PC로 옮길 때 「백업 불러오기」)

[안 될 때]
- 상단 오른쪽 점이 빨강 「PC 서버 꺼짐」: start_chart.bat 을 켜고, 주소가 http://localhost:8000 인지 확인.
- 야후 종목이 갑자기 안 나옴: 야후가 구조를 바꾼 경우가 많습니다. 「start_chart.bat update」 또는
  명령 프롬프트에서 pip install -U yfinance 후 다시 켜기.
- 점검: 명령 프롬프트에서 이 폴더로 이동 후  python chart_server.py --selftest
- 바이낸스가 안 나옴: VPN·백신·회사 방화벽이 fapi.binance.com 을 막는지 확인.

[이용 조건]
- 차트 엔진: TradingView Lightweight Charts (Apache-2.0). 차트 왼쪽 아래 TradingView 로고는 라이선스상 표시해야 합니다.
- 야후 파이낸스 데이터: 개인 용도로만. 다른 사람에게 데이터를 팔거나 서비스로 공개하려면 유료 데이터가 필요합니다.
- 코인게코: 출처 표기 필요(종목 찾기 화면에 표시됨).
- NWE 계산은 LuxAlgo 원본(CC BY-NC-SA 4.0, 비상업)을 그대로 옮긴 것이라 이 도구를 판매할 때는 빼야 합니다.
- 후보를 좁히는 도구일 뿐, 수익을 보장하지 않습니다.
