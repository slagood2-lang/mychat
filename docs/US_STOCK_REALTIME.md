# 미국 주식 실시간 시세

## wedomview는 어떻게 하나 (2026-11-25 확인)
- 브라우저가 외부 시세 회사에 직접 붙지 않습니다. **자기 서버**(`wedomview.com/api/us/...`, Cloudflare 뒤)가 시세를 받아 두고 브라우저에 나눠 줍니다.
  - `/api/us/quotes?s=NVDA,AAPL` → 여러 종목 현재가·변동%·거래량·전일 종가 (5초 캐시)
  - `/api/us/quote/NVDA` → 한 종목 + 장 구분(`ph: "pre"` 프리마켓 등)·다음 장 시작 시각
  - `/data/chart/US:NVDA/1` → 1분봉 (1·5·15·60·240분, 일·주)
  - 정규장 09:30–16:00 / 확장 04:00–20:00, 미국 휴장일 목록을 화면에서 따로 처리
- 그 서버가 어느 시세 회사에서 받는지는 밖에서 알 수 없습니다. 이런 공개 서비스는 보통 유료 데이터 계약(거래소 재배포 허가 포함)이 있어야 합니다.
- 별도로 「USDT 무기한」 주식 목록(NVDA·TSLA 등)은 바이비트·바이낸스의 **주식 무기한 선물** 시세라 24시간 움직이고 실제 나스닥 가격과 조금 다를 수 있습니다.
